# 现行有效司法解释与指导性案例

> 不只是一份全文合集，而是带**效力状态**的中国法律数据：哪条还有效、何时施行、官方原文在哪。

在线阅读与检索：<https://susujuris.cn/data.html>

## 这个库解决什么问题

法律文本本身到处都是，难的是三件事：

1. **这条司法解释还有效吗？** 本库只收现行有效文本，已废止、已被修改的旧文本一律剔除，并记录剔除依据；
2. **指导案例还能不能引？** 279 篇里 6 篇已被最高人民法院通知「不再参照与适用」，本库如实标注，不混进正常案例；
3. **引用时怎么给出处？** 每篇都带法释号／案例编号、公布与施行日期、官方链接，可直接写进脚注。

## 数据

| 目录 | 内容 | 数量 |
|---|---|---|
| `judicial-interpretations/` | 现行有效司法解释全文（Markdown） | 259 |
| `guiding-cases/` | 最高人民法院指导性案例全文（Markdown） | 279 |
| `data/shifashi.json / .csv` | 司法解释元数据 | 259 |
| `data/guiding-cases.json / .csv` | 指导性案例元数据 | 279 |

范围与口径见 [STATUS.md](STATUS.md)；元数据字段：

- 司法解释：`n / slug / title / type / fsNo / pubDate / impl / url`
- 指导性案例：`n / title / plain / cause / year / pub / url / kw / laws`

## 怎么用

- **读**：直接打开 Markdown；每个文件头部有 YAML 元数据；
- **查**：CSV 用 Excel／WPS 打开，按类型、年份、施行日期筛选；
- **建**：JSON 导入 SQLite／Notion，或作为检索、RAG 的目录层（正文再回官方链接）；
- **引**：

```
苏酥. 最高人民法院现行有效司法解释库（v2026.10）[DB/OL]. 苏酥学法, 2026-10-21.
https://susujuris.cn/data.html.
```

## 更新

版本号形如 `v2026.10`，每次核对在 [STATUS.md](STATUS.md) 记一条变更。状态判断依据最高人民法院历次废止、修改决定（含法释〔2020〕16号民法典配套清理清单），与官方正文交叉比对。
